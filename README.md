# Real-Time Chat Application (Microservice Based)

A real-time chat application built using the **MERN Stack** and **Socket.IO** with a microservice-based architecture. This project allows registered users/students to communicate instantly through real-time messaging with online user tracking and notification support.

## 🚀 Features

### 🔐 Authentication System
- User registration
- User login
- Secure authentication flow
- User session management

### 🏠 Welcome Page
- Starting page of the application
- Provides two options:
  - Login
  - Register

### 🏡 Home Page
After successful login, users are redirected to the home page where they can:

- View all registered students/users
- See currently online users
- Select any online user to start chatting

### 💬 Real-Time Chat System
- One-to-one real-time messaging
- Instant message delivery using Socket.IO
- Live communication between connected users
- Chat interface for sending and receiving messages

### 🔔 Notification System
- Real-time message notifications
- If a user is logged in but not currently on the chat page:
  - They receive a notification when another online user sends a message
- Helps users stay updated with incoming messages

### 🟢 Online User Tracking
- Displays active users
- Real-time online/offline status updates using Socket.IO
